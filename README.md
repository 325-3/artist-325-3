# 325_3 Official Website

アーティスト「325_3」の公式ウェブサイトです。

## 🎨 デザインコンセプト

ミニマルで洗練されたデザインを採用し、アーティストの世界観を表現しています。

## 🛠️ 技術スタック

- **HTML5** - セマンティックなマークアップ
- **CSS3** - モダンなスタイリング（グラスモーフィズム、アニメーション）
- **Vanilla JavaScript** - 軽量でシンプルなインタラクション

## 🔒 セキュリティ

以下のセキュリティ対策を実装しています：

- Content Security Policy (CSP)
- X-Content-Type-Options
- X-Frame-Options
- Referrer Policy
- 外部リンクの安全な属性設定

## 📁 プロジェクト構造

```
.
├── index.html          # メインHTMLファイル
├── style.css           # スタイルシート

│   ├── hero_bg.png

│   └── ...

```

## 🚀 ローカル開発

1. リポジトリをクローン
```bash
git clone https://github.com/[username]/325_3-official-website.git
```
